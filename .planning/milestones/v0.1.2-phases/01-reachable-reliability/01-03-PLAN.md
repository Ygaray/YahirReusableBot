## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| OS `/proc` filesystem → hub identity guard | `/proc/<pid>/cmdline` bytes are supplied by the kernel but their CONTENT is chosen by whatever process holds that PID. | hub identity guard → consumer reload path | The guard returns a boolean the consumer acts on by sending a signal. A False positive is not a wrong answer — it is a delivered SIGHUP. |
