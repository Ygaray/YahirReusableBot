- **The architectural inversion, stated first and unmissably.** Every other seam in this guide is "the
  host implements a Protocol the module calls." SEAM-08 is the reverse: the module supplies callable
  mechanism plus a registration entry point, and the HOST wires it into its own logging configuration.
  There is no redaction Protocol to implement and none to go looking for. This is DOCS-04's literal ask
  and the single most useful sentence in the section for a future reader.
- **What the module owns versus what the host injects.** The module owns the pattern pair type and its
  literal mode, the substitution loop, the vetting registration call, the sink, the counter, the
  self-check and the optional processor. The host owns every pattern's CONTENT, the decision to wire,
  the wiring itself, and the disablement value. The module hardcodes no pattern and never configures
  logging on its own initiative.
- **Recipe 1 — required.** Pass the writer as the render target of the host's own logger factory. Show
  it as the guide shows other wiring: a short, concrete snippet in the host's composition root.
- **Recipe 2 — optional, broader.** The host assigns the writer over the process's standard error
  stream in its own composition root, which additionally covers stdlib logging records, bare prints and
  third-party library output. State the ordering constraint as a hard requirement, not a tip: it must
  happen before any stdlib logging handler is constructed, because a handler resolves the stream at
  construction time and an already-bound handler keeps writing to the original one. State plainly that
  the module never performs this assignment itself — the host's own visible line of code does, which is
  what keeps a security-relevant process-wide mutation auditable.
- **Proving it is on.** Name the self-check, say it raises rather than returns a status, and give the
  consumer-side discipline the module cannot enforce structurally: call it once at boot AND again after
  any reconfiguration, because the logging library's configuration is global mutable state and a second
  configuration call can drop the wiring with no error of its own. Describe the opt-in deep option
  honestly: it proves the scrub code path executes against a non-secret probe entirely in memory and
  catches an empty pattern set and a disabled writer; it does NOT prove that any particular secret shape
  is covered, and it deliberately does not require a canary pattern.
- **The optional processor.** Additive defence-in-depth for field-level scrubbing before serialization,
  with its chain-order precondition (after the exception formatters) and — stated at least as
  prominently as its benefit — that it is NOT a substitute for the sink, because some renderers format
  exception output into their own buffer regardless of where the processor sits. Mention that the
  self-check warns, never raises, about ordering, and that a host's own redaction processor can opt into
  that check by setting the published marker attribute.
- **Telemetry, described accurately.** The counter is readable off the live writer instance and an
  optional push hook can be supplied. Say what it actually counts: changed writes, not individual
  substitutions, monotonic for process lifetime, so a rate is obtained by diffing two reads. Do not let
  a reader infer a per-substitution metric.
- **Known limitations, as their own clearly-labelled block.** Four items, each one sentence of what and
  one of what to do about it: (a) the self-check cannot see a writer nested inside the host's own
  proxy and will raise — wrap the stream with the module's writer FIRST, then any additional proxy;
  (b) the self-check reads a private attribute of the logging library's shipped factories and the
  dependency is pinned with a lower bound only, so a future release can break it — it fails loudly with
  a distinct message naming the installed version rather than silently passing; (c) recipe 2 is a
  Python-level stream proxy and therefore cannot intercept writes made through the stream's raw byte
  buffer or a direct file-descriptor write; (d) a `name=value`-shaped pattern whose value boundary
  excludes a quote or backslash can under-redact a secret whose own value contains one of those
  characters inside already-escaped text — literal-value mode matches verbatim and sidesteps it.
- **Implemented / Deferred split** closing the section, mirroring how SEAM-01 and SEAM-03 present
  theirs, and consistent with the Deferred column added to the summary table.
