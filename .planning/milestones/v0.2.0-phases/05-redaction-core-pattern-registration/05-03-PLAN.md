<flagged_assumptions>
Planner-made contract decisions and deviations, surfaced so they are reversible rather than silent.
None of these contradicts a locked D-4x/D-5x decision; each fills an edge the locked decisions left
open or corrects a research sketch.

1. **Empty / whitespace-only literal is rejected at construction** (plan 05-01, REDACT-06 empty
   edge). Not specified by D-51. Resolved by direct analogy to the standing D-41 empty-marker reject
   in `discord/panelkit.py`: a zero-width pattern matches at every position and would shred the whole
   text. If the developer prefers a silent no-op instead, this is a one-line change in
   `RedactionPattern.literal` plus one test.

2. **`RedactionPattern` gets an explicit, source-eliding `__repr__`** (plan 05-01, prohibition PR-01,
   threat T-05-02). Beyond RESEARCH.md's Architecture Pattern 1 sketch, which uses the default
   dataclass representation. Rationale: ROADMAP success criterion 4 requires a literal secret to be
   blocked "including inside a `repr()` of an object that embeds it", and
   `RedactionPattern.literal(secret)` IS such an object — the default representation prints the
   secret verbatim. The elision is unconditional because a consumer can build a secret-bearing
   pattern without the `literal` constructor. Cost: `repr()` of a non-secret pattern no longer shows
   its source. Reversible by deleting the method.

3. **`register_patterns`' rejection message names the offending entry by INDEX, not by pattern
   source** (plan 05-02, prohibition PR-02). RESEARCH.md and PATTERNS.md both sketch the message as
   interpolating the pattern source. Same reasoning as (2): a rejected entry may be a literal whose
   source is the plaintext secret. An index is unambiguous because the consumer authored the
   sequence. Reversible, but reverting reopens the leak.

4. **The ReDoS probe is an escalating ladder with a cumulative-elapsed check after every search, NOT
   a single long probe** (plan 05-02, threat T-05-06). This CORRECTS RESEARCH.md Architecture
   Pattern 3, whose `_REDOS_CORPUS` uses 8,000-character probe strings timed after a single
   `pattern.search(...)` returns. Stdlib `re` cannot be interrupted, so a catastrophic pattern
   against an 8,000-character probe runs to completion — the vetting call hangs, causing exactly the
   failure it exists to prevent. RESEARCH.md's own Assumptions Log A1 implicitly agrees, citing
   `"a"*30` rather than `"a"*8000`. The ladder's fine tier grows by +2 repeats per rung, bounding the
   overshoot. Budget, ladder and corpus remain internal implementation details, tunable without
   touching the public signature.

5. **`test_register_patterns_accepts_proven_appid_pattern` renamed to
   `..._accepts_proven_boundary_pattern`** (plan 05-02). `05-VALIDATION.md`'s draft name embeds a
   consumer domain noun. The AST litmus gate scans `yahir_reusable_bot/` only, so the draft name
