## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| hook value → log record | The `label` value crosses from caller-controlled data into a rendered log line. Interpolating caller data into a log message is the class of bug that produces log-injection and unstructured, ungreppable output. |
| OS process table → identity guard | `/proc/<pid>/cmdline` bytes from an arbitrary, possibly recycled PID cross into a match decision that gates a SIGHUP. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-07-05-01 | Tampering | `_best_effort_hook` log message | medium | mitigate | Interpolating a caller-supplied label into the event string lets that value alter the rendered message shape (log injection into an unstructured line). Carrying it as a structured `label=` field makes the event string a fixed literal; pinned by `test_best_effort_hook_event_string_is_identical_across_labels`, which drives a label containing formatting characters. |
| T-07-05-02 | Repudiation | operator log searchability | low | mitigate | An f-string-baked label cannot be filtered or aggregated by a log consumer. The structured field restores that, matching the hub-wide `_log.warning("message", key=value)` discipline. |
| T-07-05-03 | Elevation of Privilege | `_argv_matches_marker` → SIGHUP delivery | high | mitigate | A false positive signals an unrelated recycled PID whose default SIGHUP disposition is terminate. D-61 ratifies the current false-positive-free scan (exact `-m` token prefix) and REJECTS decoding CPython's bundling grammar, whose whitelist gaps would convert benign false negatives into this exact false positive. Enforced by the plan prohibition and the acceptance criterion that `identity.py`'s diff contains no executable change. |
| T-07-05-04 | Information Disclosure | hook failure logging | low | accept | The handler deliberately logs outcome-only and never the exception payload or the hook's arguments — the pre-existing "never mask the engine result" posture, unchanged by this plan. |
| T-07-05-SC | Tampering | npm/pip/cargo installs | high | mitigate | Zero package-manager installs. `structlog.testing` ships inside the already-pinned `structlog>=26.1.0` (`07-RESEARCH.md` § Package Legitimacy Audit); `[project.dependencies]` and `[dependency-groups].dev` are untouched. |
