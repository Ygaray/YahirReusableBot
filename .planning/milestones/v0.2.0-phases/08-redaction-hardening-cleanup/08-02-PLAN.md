## Plan-time decision: the `on_error` payload shape

CONTEXT.md leaves this to Claude's Discretion ("whether the hook's signature/payload mirrors
`on_redaction` exactly or carries the offending pattern identity — decide at plan time"). Decided
here, with the reasoning recorded so the executor does not re-open it:

**Decision: `on_error: Callable[[re.error], None] | None = None`, invoked as `hook(exc)` with the
caught exception, one positional argument — the same arity as `on_redaction`.**

- **Not the offending pattern.** `redact_secrets` loops over `patterns` internally
  (`core.py:173-174`), so the sink cannot tell WHICH pattern raised without re-running the set one
  at a time on a failure path. That is exactly the "re-run patterns to compute a number nobody acts
  on" cost D-58 already rejected for the counter.
- **Not a no-arg call.** A bare notification carries no diagnostic value; an operator learns that
  something was withheld but nothing about why, which is barely better than the silence D-01 is
  fixing.
- **The exception is the natural payload.** It is already in hand at the `except` site, it names
  the real defect (e.g. an out-of-range group reference in a replacement template), and it matches
  `on_redaction`'s single-positional-argument registration shape.
- **The one risk is converted into a gate, not assumed away.** In CPython the `re.error` raised by
  a bad replacement template carries the TEMPLATE as its `pattern` attribute, not the compiled
  regex source — so a `literal()`-built secret does not travel with it. That is an implementation
  detail, and this codebase does not rest secret-containment on implementation details. Task 1
  therefore ships a standing gate asserting the sentinel is absent from the exception's `str`,
  `repr`, and every string-valued attribute. If a future CPython changes this, the suite goes red
  and the hub finds out — the same posture the guide's own "fails loudly rather than silently
  passing" limitation already takes toward the logging library's private attributes.
