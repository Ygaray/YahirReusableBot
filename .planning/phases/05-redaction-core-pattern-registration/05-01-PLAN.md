  a LOCAL only; never mutate the argument or the sequence.
- The function must NEVER raise (D-52) — no try/except, no type guard, no validation. Strict
  `str -> str`; a non-`str` argument is out of contract and its tolerance belongs to the Phase-6 seam.

- Pattern compilation must never occur inside this function — it accepts only already-built
  `RedactionPattern` objects, which is what makes late compilation structurally impossible rather than

- Docstring must state the ordering rule (sequential, registration order, each pattern operating on
  the previous one's output) and the Unicode contract (code-point matching, no normalization, no case
  folding by the core — a caller needing NFC/NFD equivalence normalizes before calling).
